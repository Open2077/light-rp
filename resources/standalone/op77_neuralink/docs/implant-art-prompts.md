# Neural-Link installation — red / blue asset set

Generated with the built-in imagegen tool. Fifteen independent transparent PNG originals, encoded as WebP without removing or rebuilding alpha. The previous silver/white set has been replaced.

Runtime source: `neuralink-ui/public/img/implant/layers/`. Vite copies these into `resources/standalone/op77_neuralink/web/img/implant/layers/`.

The installation uses a 14-second clock, a black focus veil (76%), camera cuts / push-ins, anchored discharge sprites, optical scans and a final reveal of the live game. All labels remain DOM text. No background artwork or game screenshot is shipped in the installation.

Normal phase durations: hardware 900 ms; firmware 1800 ms; coupling 2800 ms; routing 2300 ms; calibration 2700 ms; signature 1700 ms; online 1800 ms. Network delay can hold registration; only a successful install response permits the online reveal. Reduced motion disables camera movement, discharges and shutter cuts. Native sounds remain on the two existing game audio slots; routing intentionally replaces the insertion tail.

## Shared prompt

Use case: stylized-concept. Production transparent-alpha game VFX sprite for a premium Cyberpunk 2077 Kiroshi neural implant installation HUD composited over live gameplay. This is ONE isolated reusable component, NOT a scene, NOT an artwork, NOT a complete interface. Unified gritty Night City industrial cyberware aesthetic, precise engineered microcircuit detail, aggressively sharp neon scarlet red #ff3048 and electric ice-blue #25c8ff light, dark gunmetal/navy materials. Strong red/blue separation, absolutely no yellow gold amber green violet or milky white. Fine technological scan interference and damaged digital edges, controlled luminous bloom only at emitters, transparent holes and transparent background, clean alpha silhouette. No background rectangle, no environment, no lettering, no digits, no logo, no watermark, no frame. Center subject with generous transparent padding. High detail physically convincing cyberware, not fantasy magic, not stock abstract wallpaper.
