# Tabletop geometry

These are original triangulated 3D models generated by
`python3 tools/generate-board-game-models.py`. The generator writes the runtime
`shared/board_game_models.lua` and matching editable Wavefront OBJ sources here.
Coordinates are metres, Z up. The playable board spans -0.5..0.5 on X/Y,
with a 1.12 m outer frame; its top lies at Z=0.001. Piece origins are at the
centre of their base, Z=0. Pieces fit within a 0.068 m diameter.

`LightRpBoardGameModels.board(gameKind)` returns a triangle array.
`LightRpBoardGameModels.piece(pieceKind, side, gameKind)` returns a triangle array.
Triangles have `{a={x,y,z},b={x,y,z},c={x,y,z},color="#RRGGBBAA"}`.
Tables are immutable; the renderer transforms them into separate world batches.

The generated module registers lightweight factory functions during activation.
It builds each geometry table only when `board` or `piece` first requests that
model, then caches and returns the same immutable reference. No geometry is
allocated at startup. This keeps activation at 58 Lua instructions instead of
approximately 39,300 for the previous eager literal. This distinction matters
because the entire gamemode shares the client's activation execution budget.

`python3 tools/generate-board-game-models.py --verify-lua` additionally checks
the lazy startup instruction count, first-use geometry and cache identity under
Lua 5.4 with the optional `lupa` test dependency. Maximum first-use cost is
12,693 instructions for the Connect Four grid; repeated calls use fewer than
100 instructions. The default generator still requires only Python's standard
library. First-use construction must happen during normal client rendering,
never by preloading every model during resource activation.

The runtime uses the supported `Open77.debugDraw.set` solid-triangle geometry
API, with per-batch splitting and proximity culling in the client renderer.
It does not register RED4 `.mesh`/`.ent` props. OBJ files are editable source
geometry, not assets which `Open77.props.create` can load. OPX's pool setup was
consulted: that pipeline requires compiled CR2W visual hosts and ArchiveXL links,
so supplying OBJ paths as native prop models would produce placeholders.

Geometry budgets: initial chess 1,950 triangles (5,850 vertices), checkers with
all 40 pieces crowned 2,196 triangles (6,588 vertices). This fits one nearby board
within the native 8,192 input-vertex quota, leaving room for selection lines.
Other resources share native geometry limits; the client must select nearby
boards and handle quota refusals. Maximum 256 triangles per batch, 32 tags per
resource, 128 total native batches. The generator checks every triangle for
finite coordinates, nonzero area and piece footprint bounds.

Rendering, lighting appearance, camera legibility, interaction and animation
still require an in-game test. These procedural surfaces have no physics,
collision or baked materials. They require no new game mod/preload archive.

## Connect Four

`board("connect4")` supplies a vertical blue seven-column, six-row frame with
open octagonal slots and supporting feet. Its front faces negative local Y;
the slot centres are `x=(column-4)*0.14`, `y=0`,
`z=(6.5-row)*0.14+0.04`, with row 1 at the top and row 6 at the bottom.
The frame is 1.06 m wide and approximately 0.91 m high. These coordinates use
the same local-to-world yaw transform as the horizontal tabletop games.

`piece("disc", side, "connect4")` supplies a cylinder centred at the origin,
with its face in the XZ plane, radius 0.052 m and depth 0.05 m. Compatibility
side `white` is red (`#F04D4DFF`); `black` is yellow (`#FFD34DFF`). The client
animates the disc's centre from above the selected column into its final slot.

The grid uses 744 triangles; each disc uses 32. A completely filled board uses
2,088 triangles / 6,264 vertices, below the native 8,192-vertex quota. Slot
annuli are front-facing surfaces; the surrounding frame and discs are closed
3D geometry. The interactive camera should view the front of the frame.
The generated OBJ collection now contains 21 models in total.
