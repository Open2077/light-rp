# Weapon and grenade catalogue

Source: [Cyberpunk 2077 Weapons](https://cyberpunk.fandom.com/wiki/Cyberpunk_2077_Weapons).

The index contains **198 inventory candidates**, including **9 grenade types**. Each has a local PNG with a stable item name and recorded SHA-256. **195** records were found in the Open77 2.31 catalogue. Coronation, Sihil and Boar Carver have images but no verified record in that catalogue.

The full native reference contains 1,925 rows, including aliases, NPC/test weapons, vehicles and cyberware. It is evidence for the crosswalk, not an inventory grant allowlist.

Runtime integration currently supports Lexington, Nue and the nine grenade types. The other rows are catalogued for integration; listing an item or finding its record does not establish native equip/reload compatibility. See [grenade design](grenades-inventory-design.md).

## Asset provenance

Illustrations were downloaded from the image links on the user-supplied wiki index, at up to 256 px width, preserving PNG transparency. The catalogue records every source page, source image URL, original filename, byte count and SHA-256. Game artwork remains attributed to its original rights holders (CD PROJEKT RED and the associated game contributors); the wiki is the distribution source. These images do not receive the code repository’s license.

Import/check: `python3 tools/import-weapon-assets.py --check`. To refresh, install `beautifulsoup4` and use `--fetch`; the importer uses the public MediaWiki API and downloads local assets. Runtime WebUI does not load third-party image URLs.
