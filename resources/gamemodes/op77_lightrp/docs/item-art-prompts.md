# Inventory asset generation

Generated with the built-in image_gen tool (not the API/CLI), 2026-09-20. Individual transparent PNGs were copied into `ui/public/img/items/`; Vite ships them in the resource's `web/img/items/`. These are new illustrations, not extracted game assets.

Each prompt is the following base, replacing its Subject line with the matching entry below. Originals remain in the generating machine's Codex generated_images directory; the project has its own independent copies.

```text
Use case: stylized-concept
Asset type: a single transparent PNG inventory item icon for a Cyberpunk-inspired roleplay game.
Subject: one compact clear filtered-water bottle with angular industrial plastic body, blue cap, pale blue water and a simple yellow/black utility label with an abstract droplet symbol.
Style: premium realistic 3D game prop render, restrained worn industrial detailing, believable everyday Night City consumer goods, readable at 80px.
Composition: square canvas, single centered object, three-quarter view slightly from above, entire object visible, occupies 80% of canvas with comfortable margins.
Lighting: neutral soft studio key light, subtle cool edge light, crisp silhouette.
Background: genuinely transparent alpha, no checkerboard drawn, no floor, no scenery, no cast shadow beyond the item.
Constraints: NO words or typography, no logos, no UI border, no decorative particles, no additional objects, no watermark.
```
